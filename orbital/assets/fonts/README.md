# Font

The HUD/menus currently use the system font. At **M4/M6** we load one geometric
variable font via `expo-font` for the big, tight, confident score numbers (§8).

Recommended: **Space Grotesk** or **Sora** (both OFL-licensed, free to bundle).

Drop the file here as `assets/fonts/Orbital.ttf` (or update the name in the
`useFonts` call) and it will be picked up on boot.
